#🐱Mewmew Chatbot

A simple beginner-friendly chatbot made with Python.

Mewmew can greet the user according to the current time and respond to a few basic questions using predefined responses.

## ✨ Features

* 🕐 Time-based greetings
* 👋 Basic conversation
* 💬 Predefined chatbot responses
* 🔄 Continuous conversation using a `while` loop
* 🛑 Type `bye` to end the conversation
* 🐍 Built using basic Python concepts

## 🛠️ Technologies Used

* Python
* `datetime` module

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python chatbot.py
```

## 💬 Example

```text
What is your name: Alex
Good Afternoon Alex

Welcome! I am your favourite chatbot, Mewmew 🐱
You can ask me anything. Type 'hello' to start the chat.
Type 'bye' to stop the chat.

You: hello
Mewmew: Hi! How can I help you?

You: how are you?
Mewmew: I am good. How is your day going?

You: bye
Mewmew: Have a good day. Bye bye!
```
